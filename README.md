# Rioja Tycoon Refactor

Base limpia para La Rioja Agro-Tycoon.

Incluye:
- Vite + React + Tailwind
- Zustand como store global
- Escena 3D desacoplada
- Menús de finanzas, RRHH, infraestructura, vivienda e I+D
- Guardado local y exportación JSON

## Build
```bash
npm install
npm run build
```

## Cloudflare Pages
- Build command: `npm run build`
- Output folder: `dist`
